# CARTS APP

Проект представляет собой приложение для просмотра карточек товаров с аутентификацией и навигацией по страницам.

Для доступа к основной странице с карточками товаров необходимо пройти авториззацию, ввести логин и пароль одного из пользователей. Например: логин - "emilys", пароль - "emilyspass"

## Деплой проекта:

https://darya-dubovik.github.io/Carts-App/

### Проект содержит 3 страницы:

- страница авторизации пользователя с полями для ввода логина и пароля
- основная страница с карточками товаров и их кратким описанием
- страница конкретного товара с его детальным описанием

#### Структура проекта:

```CARTS APP/
│
├── dist/ - результат cборки проекта
├── node_modules/ - установленные зависимости npm
│
├── src/ - исходники приложения
│ ├── assets/ - статические файлы (изображение)
│ ├── components/ – общие и переиспользуемые React-компоненты
│ ├──constants/ – константы для работы с API
│ ├──features/ – Redux slices и логика состояния приложения
│ ├──pages/ – основные страницы приложения
│ ├──routes/ – маршрутизация и защищённые маршруты
│ ├──services/ – API-сервисы: авторизация и получение данных о товарах через RTK Query
│ ├──utils/ – вспомогательные функции и хелперы
│ ├──App.jsx - главный компонент приложения, точка входа в React Router
│ ├──index.js - рендер приложения в DOM, подключение Redux store и Router
│ ├──store.js - центральный Redux store приложения, подключение слайсов и RTK Query для API
│ ├──style.css - глобальные стили приложения
│ └──template.html - HTML-шаблон для сборки приложения
│
├── .gitignore - файл, содержащий намеренно неотслеживаемые файлы и каталоги, игнорируемые Git
├── babel.config.cjs - файл конфигурации Babel для поддержки современного JavaScript и JSX.
├── package-lock.json - зафиксированные версии всех установленных пакетов, читаемые npm
├── package.json - настройки npm
└── webpack.config.cjs - основная конфигурация Webpack
```

##### Основные технологии:

- React-компоненты с разделением логики и представления
- проект собран с помощью Webpack
- cостояние и данные обрабатываются через Redux Toolkit / RTK Query
- запросы выполняются к DummyJSON API
- использована Material UI-библиотека для компонентов интерфейса
- настроена маршрутизация с помощью React Router
